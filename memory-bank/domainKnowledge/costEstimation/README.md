# domainKnowledge/costEstimation/ — 報價資料夾

> 對應 V6.0 §1-5-1-3。這個資料夾放報價相關的知識：單價行情、估價方法、歷史報價紀錄。

## 這裡放什麼

- 各項工程項目的單價行情表（例如：拆除、水電、泥作、木作、系統櫃等各自的市場行情）。
- 估價邏輯/公式（例如：坪數換算、材料損耗率、人工計算方式）。
- 歷史報價案例（哪個案場、報了多少、後來實際成本多少，作為未來估價校準依據）。

## 檔案命名建議

```
domainKnowledge/costEstimation/
  ├── 單價行情表.md
  ├── 估價邏輯與公式.md
  └── 歷史報價案例/
        ├── 星鑽_報價紀錄.md
        └── ...
```

## 使用規則

1. 單價行情表建議標註「資料時間」，因為材料/人工價格會隨時間變動，避免用過時價格報價。
2. 若某次報價後來被業主壓價或發生實際成本落差很大，記錄下來並分析原因，避免下次重複誤判。
3. 目前內容留白，之後由人逐步整理丟入。

## 目前狀態

⚠️ 尚未有任何報價資料，待補。
