# domainKnowledge/projectRecords/ — 案場記錄資料夾

> 對應 V6.0 §1-5-1-2。這個資料夾放各個實際案場的記錄，例如圖說審查歷程、決議事項、現場狀況。

## 這裡放什麼

- 每個案場一個獨立資料夾（例如：`星鑽/`、`成德/`、`仁發和/`、`和館/`）。
- 每個案場資料夾底下可包含：
  - 審圖歷程記錄（哪次送審、發現什麼問題、如何處理）
  - 現場勘查筆記
  - 與業主/廠商的重要決議事項摘要
- 圖說檔案本身（DWG/PDF 等）不放這裡，這裡只放**文字記錄與摘要**，圖說原始檔案路徑見 `techContext.md` 的案場目錄表。

## 檔案命名建議

```
domainKnowledge/projectRecords/
  ├── 星鑽/README.md         ← 案場總覽
  ├── 星鑽/2026-08-20_審圖記錄.md
  ├── 成德/README.md
  └── ...
```

## 使用規則

1. 每筆記錄建議標註日期、參與人員、決議內容。
2. 若某案場的問題後來變成「所有案場都適用」的通用規則，應該把該規則搬到 `regulations/` 或對應的規範文件，這裡只保留「這個案場當時發生了什麼」。
3. 目前內容留白，之後由人逐案建立。
