# domainKnowledge/equipmentData/ — 設備資料資料夾

> 對應 V6.0 §1-5-1-6。這個資料夾放各類設備的規格、廠牌型號、安裝需求等資料。

## 這裡放什麼

- 常用設備的規格表（例如：空調、給排水設備、消防設備、電氣設備等）。
- 廠牌型號對照與選用邏輯（哪些案場慣用哪個廠牌、為什麼）。
- 安裝需求與限制（例如淨高、預留孔徑、供電需求）。

## 檔案命名建議

```
domainKnowledge/equipmentData/
  ├── 空調設備.md
  ├── 給排水設備.md
  ├── 消防設備.md
  ├── 電氣設備.md
  └── ...
```

## 使用規則

1. 審圖或估價時若牽涉設備規格判斷，先查此資料夾，找不到才標記「需要人決定」。
2. 設備規格若有型號停產、規格更新，記得標註日期並更新，避免用到過時資訊。
3. 目前內容留白，之後由人逐步整理丟入。

## 目前狀態

⚠️ 尚未有任何設備資料，待補。
