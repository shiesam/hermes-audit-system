# domainKnowledge/materialsGlossary/ — 材料對照資料夾

> 對應 V6.0 §1-5-1-4。這個資料夾放材料名稱對照、規格說明、常見替代品資訊。

## 這裡放什麼

- 材料俗名 ↔ 正式名稱/規格對照表（例如工地慣用說法對應到圖說標註的正式名稱）。
- 各類材料的規格參數（尺寸、耐燃等級、承重等）。
- 常見替代材料與適用情境（例如缺料時可替代的等級品項）。

## 檔案命名建議

```
domainKnowledge/materialsGlossary/
  ├── 板材類.md
  ├── 五金類.md
  ├── 防火材料.md
  └── ...
```

## 使用規則

1. 審圖或估價時若遇到圖說標註材料與現場慣用說法不一致，應先查此資料夾對照，找不到才問人，並把新對照補進來。
2. 材料若有國家標準字號（CNS 等），一併註記，方便日後查證。
3. 目前內容留白，之後由人逐步整理丟入。
