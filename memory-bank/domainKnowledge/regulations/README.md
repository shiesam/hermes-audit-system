# domainKnowledge/regulations/ — 法規資料夾

> 對應 V6.0 §1-5-1-1。這個資料夾放審圖時要依據的法規、標準、檢查清單。

## 這裡放什麼

- 各類建築/工程法規條文整理（例如：建築技術規則、消防法規、無障礙設施規範、用電相關規定等）。
- 每一類法規建議獨立成一個檔案，不要全部塞在一個檔案裡。
- 法規異動、地方政府補充規定，也放在對應檔案裡並標註更新日期。

## 檔案命名建議

- 用中文法規名稱直接命名，例如：
  - `建築技術規則.md`
  - `消防法規.md`
  - `用電相關規定.md`
  - `無障礙設施規範.md`
- 若同一類法規內容很多，可以再用子資料夾細分（例如 `消防法規/室內裝修.md`、`消防法規/防火區劃.md`）。

## 使用規則

1. **審圖判斷時，這裡是唯一依據**，找不到對應條文就標記「需要人決定」，寫進 `activeContext.md` 待辦清單，不可自行猜測或推論法規內容。
2. 每份法規檔案開頭建議標註：資料來源、最後確認/更新日期，方便日後判斷是否過時。
3. 目前內容留白，之後由人逐份整理丟入。

## 目前狀態

⚠️ 尚未有任何法規內容，待補。
